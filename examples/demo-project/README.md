# Projet démo

Projet vide servant de bac à sable pour tester l'extension. C'est le dossier ouvert par
la configuration de debug (F5).

Pour tester : lancer la commande « LearnPath: Importer un parcours... » et choisir
`../exemple-panier.json`. L'extension doit créer `.learn/` ici et proposer l'étape 1.

Ne pas commiter le `.learn/` généré autrement que pour un besoin de test explicite.
